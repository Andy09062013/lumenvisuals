LUMEN

Shader-like visuals for Minecraft 1.21.11 · Fabric

This server uses Lumen for its look: sunsets, sun shadows, waterfall mist and more. It's purely visual and doesn't change gameplay. Grab it below, then rejoin.
Download Lumen

Your browser might warn about a .jar file. That's normal for mods: choose Keep.

Install in 3 steps

  1. Have Fabric for 1.21.11No Fabric yet? Get the Fabric installer and install it for 1.21.11. Using Prism, Modrinth App or CurseForge? Just make a Fabric 1.21.11 instance.
  2. Get Fabric APIDownload Fabric API for 1.21.11. Lumen needs it.
  3. Drop both jars into your mods folderPut lumen.jar and Fabric API in .minecraft/mods (Windows: press Win+R, type %appdata%\.minecraft\mods). Then start Minecraft with the Fabric profile.

That's it. Rejoin the server ✓
