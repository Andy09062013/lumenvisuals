Install Lumen

  1. Install Fabric for Minecraft 1.21.11.
  2. Download Fabric API for 1.21.11.
  3. Download the Lumen JAR and place it alongside Fabric API inside your launcher's mods folder.
  4. Launch with Fabric. Press F6 or type /lumen to configure the effects.

Distant Horizons is optional. The latest source code no longer forcibly disables external fullbright packs or gamma adjustments; download builds need to be rebuilt before those changes take effect.

If a dedicated server requires Lumen, every joining player must install the client mod.
