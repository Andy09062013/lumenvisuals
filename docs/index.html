Lumen

Lumen is a visual mod for Minecraft 1.21.11 (Fabric). It adds sunsets, sun shadows, a bright sun, waterfall mist, water splashes, fire sparks, fog, fireflies and more. It only changes how the game looks, not how it plays.

This server needs Lumen to join.

Recommended: Distant Horizons

Lumen looks best together with Distant Horizons, which shows terrain far beyond your render distance. Lumen blends that far-away land into the haze and sky. It's optional: install the Fabric 1.21.11 version next to Lumen if your PC can handle it.

Download

Easiest: Download LumenInstaller.exe. Double click it, type the number for your launcher (Minecraft Launcher, Prism, Modrinth App or CurseForge) and your profile, and it installs Lumen, Fabric API and Distant Horizons for you. If your browser warns, choose Keep. If Windows says "protected your PC", click More info then Run anyway.

Manual: Download lumen.jar

If your browser warns you about the .jar file, choose Keep.

How to install

  1. Install Fabric for Minecraft 1.21.11 using the Fabric installer (or make a Fabric 1.21.11 instance in your launcher).
  2. Download Fabric API for 1.21.11.
  3. Put lumen.jar and Fabric API (and Distant Horizons, if you want it) in your mods folder (on Windows: press Win+R and type %appdata%\.minecraft\mods).
  4. Start Minecraft with the Fabric profile and rejoin the server.

In game, press F6 (or type /lumen) to change the settings. Fullbright resource packs get turned off automatically; use the Cozy fullbright option on the first settings page instead.
